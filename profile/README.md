**opensaga** is an open-source effort to preserve and modernize **LEGO Star Wars: The Complete Saga** through careful reverse engineering.

Our projects include:

- **[saga](https://github.com/opensagadev/saga)** — a decompilation of the Android x86 release, with native desktop and WebAssembly builds.
- **[saga64](https://github.com/opensagadev/saga64)** — a planned modern, portable 64-bit edition built on the knowledge gained from the decompilation.
- **PC version decomp** — a possible future project exploring the original PC release.

Follow our [progress and browser build](https://opensaga.dev/)

> OpenSaga is an independent educational and preservation project. Game assets and other copyrighted game data are not distributed.
